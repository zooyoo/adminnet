# 文件管理与预览

本说明保留文件管理的长期行为约定。前端入口为 [文件页面](../../Web/apps/web-antdv-next/src/views/system/file/index.vue)，服务实现为 [SysFileService](../../Admin.NET/Admin.NET.Core/Service/File/SysFileService.cs)。依赖版本、上传限制和存储提供者以当前项目配置为准。

## 文件读写

- 列表支持名称、日期与租户等条件。公开文件沿用共享读取语义；私有读取保留数据范围过滤，并在普通账号下限定当前租户。公开可读不等于可以跨租户修改或删除。
- 更新只写入 `FileName`、`FileType`、`IsPublic`、`FileAlias`、`DataId`。租户、创建者、后缀、物理路径、URL、大小与存储位置由服务端保留。
- 上传先校验非空、文件名、内容类型、大小与允许后缀，再判断 MD5 去重。去重范围包含当前身份、租户、公开状态、类别、业务数据、名称、后缀与目标路径；显式选择存储桶或提供者时不复用默认去重记录。
- 下载和预览通过认证接口获取内容。预览和 Base64 下载复用下载权限，批量与 Base64 上传复用上传权限；维护接口时同时核对权限映射和数据范围。
- 当前业务关联使用实体字段 `DataId`；不要只根据旧页面输入框引入缺乏持久化语义的关联字段。

## 预览与存储

前端统一预览弹窗覆盖图片、Office、PDF 和浏览器支持的音视频。不支持的格式或损坏文件应给出失败反馈；预览对象地址在关闭和身份变化时释放。Office 与 PDF 渲染依赖延迟加载，具体版本查业务应用的 `package.json` 与 lockfile。

头像明确设为公开，签名通过当前用户的认证接口读取。更新头像或签名时不删除本次去重复用的同一文件。

本地私有文件的静态地址和图片转换地址均应受访问控制。OSS、SSH 和反向代理部署须与应用权限保持一致，不能将私有上传目录直接映射为公开静态目录。历史私有资源需要公开访问时，应由有权限的用户明确设置公开状态。

## 维护与验证

后端现有用例为 [FileIsolationTests](../../Admin.NET/Admin.NET.Test/File/FileIsolationTests.cs)，桌面浏览器契约为 [file-contract.spec.ts](../../Web/apps/web-antdv-next/e2e/file-contract.spec.ts)。按改动范围选择检查；涉及真实存储、权限或租户隔离时使用独立 PostgreSQL 和测试文件核验，并确认文件记录与物理文件的清理结果。

浏览器契约或 Mock 通过不代表外部 OSS、SSH 账户和生产代理配置已通过验证。环境与命令见 [开发与验证](../development.md)。
