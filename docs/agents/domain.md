# 领域文档

## 布局

采用 single-context：全仓库共享根目录 `GLOSSARY.md` 和 `docs/adr/`，前端 workspace 包不自动划分为独立领域。

## 探索前读取

- 根目录 `GLOSSARY.md`：统一领域术语与关系。
- `docs/adr/`：读取与当前任务有关的架构决策。
- 上述资料尚不存在时直接继续，不为完成配置创建空文件，也不将缺失视为阻塞。术语与决策真正确定后，由 `domain-modeling` 按任务需要记录。

## 使用约定

- 在规格、任务标题、设计、排错和测试命名中沿用术语表，避免使用已明确排除的同义词。
- 需要的概念尚无定义时，先检查是否已有项目用语；确有缺口时留待领域建模澄清，不自行宣告新术语为既定事实。
- 方案与已有 ADR 冲突时，明确指出对应决策及重议原因，不静默覆盖。
- 保留并遵守目标模块附近的 `CLAUDE.md` 和其他适用仓库规则；本配置不替代它们。
