## 不应固化的试错

- 不因 strict mode 冲突就直接添加 `.first()` 或 `.last()`：先确认重复节点的来源与生命周期。
- 不把 `.ant-transfer-list` 或任何 CSS 类名当作跨版本公开合同。
- 不认为使用正则匹配中文空格即可解决全部按钮定位失败。
- 不把延长超时当成元素实际存在的证据。
- 不将测试脚本错误误报为业务代码缺陷；同时也不能只修选择器而忽略截图显示的真实布局问题。
- 不将某一次 `passed: true` 扩展成整个提案通过；清理、视觉、权限和外部前提仍需独立核验。

### 2026-10-09：关闭弹窗后的同名标签与切换落地页

- 适用条件：Antdv-Next 1.5.2、桌面生产构建、真实租户管理。
- 现象：弹窗已经不可见，但全页面 `getByLabel('租户名称')` 仍匹配查询栏与编辑器的两个输入框；密码弹窗的关闭按钮名称为中文“关闭”。
- 根因：关闭弹窗不代表销毁其 DOM；可访问名称受实际界面语言影响。
- 处理：查询输入限定到 `form[name="tenant-query"]`，编辑输入限定到对应 dialog；按钮名称使用脱敏 DOM 实测值。
- 验证：真实新增、编辑重开、授权、密码重置与删除闭环通过。失败诊断只记录按钮文本及标签，不记录密码输入值。
- 另一个已证实问题：切换接口返回成功、身份正确、外层布局可见，并不证明目标页可用；截图实际显示内容区 404。切换验收必须断言目标业务控件可见并复核截图，不能仅断言顶部按钮或 URL。
- 归档：`.scratch/frontend-vben-migration/issues/07-tenant-isolation-acceptance.md`。首页缺失及当前兼容入口的处理属于任务记录，不作为通用路由策略。

### 2026-10-09：真实身份初始化失败与令牌清理

- 适用条件：租户切换返回令牌后，前端再请求用户资料和菜单；隔离真实 API 与 Playwright。
- 验证方法：将真实切换响应暂缓交给页面，通过授权的真实 API 删除本脚本创建的目标租户，再原样交付先前响应。随后资料请求由真实服务返回 401，可验证原身份是否仍能访问原列表；不要把这种服务端状态编排写成 Mock 成功证据。
- 清理：显式刷新令牌可能使原 session 对象和返回对象持有同一个 accessToken。逐会话重复退出会将第二次请求命中黑名单，造成清理误报；按当前令牌去重后逐一退出，禁止在诊断中打印令牌。
- 验证结果：第 07 项真实 API 与浏览器已覆盖上述流程。跨库补充测试使用 3 份实际 SQLite 文件和真实仓储；临时目录发生打开失败后改用既有测试输出目录通过，根因未确定，不上升为通用路径限制。

### 2026-10-09：切换响应令牌、样式渲染与短生命周期打印文档

- 切换身份的真实 API helper 如自动采用响应头令牌，应以原 session 的副本发送切换请求；否则验证双租户时两个变量可能已经指向同一身份。第 08 项通过读取双方 `currentTenantId` 与隔离数据库记录定位并验证。
- Antdv-Next 1.5.2 的 `Tag` 要求 `CSSProperties` 对象；真实字典 `styleSetting` 字符串会在样式合并时触发 `CSSStyleDeclaration` 索引写异常。API 正常返回但列表停留加载时，应收集脱敏 console error；Vue 捕获的渲染异常不一定触发 Playwright `pageerror`。通过浏览器 CSS 解析器转成样式对象后，实际颜色、字重及真实桌面流程通过。
- `print-js` 在打印返回、焦点恢复后移除 iframe。测试若断言打印调用后的 iframe 长期存在会不稳定；在实际 `window.print` 调用时采集文档标题、单元格文本及图片数，可保留真实打印文档与转义断言。此方法验证输出合同，不代表授权设备实体打印通过。
- 保持业务菜单 Path 与组件路径的区别：真实隔离种子中的字典/平台参数路由分别为 `/platform/dict`、`/platform/config`，组件在 `system/` 目录。浏览器直达地址应取真实菜单，不能从源码目录推导。

### 2026-10-09：真实 Excel 存储与文件权限拒绝

- Excel 导入复用上传服务时，隔离环境必须提供真实本地上传路径、大小和 MIME 配置；仅有 SQLite 不足以运行完整导入。第 09 项补充隔离 wwwroot 配置后原导入流程通过，最后检查 SysFile 与物理临时文件均清空。
- 非统一响应的文件端点拒绝可能直接返回 HTTP 401/403、没有 Content-Type 和 JSON；验收 helper 应先判断 HTTP 拒绝，再解析业务 JSON，避免把正确拒绝误报为解析错误。
- 不能从 API 返回 PK/XLSX 就推断有权：第 09 项用真实无权限账号复现了未登记菜单权限默认放行的问题。成功文件与拒绝文件需分别验收。
- 外部 AI 配置由用户明确授权后才注入隔离进程；只输出字段存在性和测试结论，绝不输出密钥，不将含密钥的用户配置纳入代码提交。真实模型不预设唯一译文，核验实际返回、必要占位符和持久化。

### 2026-10-09：站点品牌与虚拟租户选择器

- Antdv-Next 1.5.2 的虚拟 Select 同时产生用于辅助技术的 `role=option` 节点和可点击的 `.ant-select-item-option`。第 10 项租户切换中，前者匹配标签但不能完成真实点击；记录最小 DOM 后，限定可见下拉层中的业务文本完成切换。不能把 `getBoundingClientRect().height > 0` 单独视为可点击证明。
- 匿名租户切换验收先核验真实 `hideTenantForLogin` 配置。需要临时打开时，通过隔离 API 修改并在清理阶段恢复，不把隐藏选择器的既有行为判为切换缺陷。
- 图片上传成功、API 返回图片字节与生产页面实际加载是三个检查点。第 10 项分别验证字节一致、浏览器图片 `naturalWidth > 0` 及稳定截图，发现并修正了缺少 API 代理前缀的问题。
- 视觉验收同时核对品牌页脚。第 10 项标题和 Logo 正确后，截图仍发现固定备案号与版权文字，补为当前租户值后需用最终构建复测。

### 2026-10-09：隔离短信、验证码和后台进程管道

- 使用已有 `SMS.Custom` HTTP 合同连接本机收件服务，可覆盖真实后端发送、缓存、浏览器取码及登录，不代表运营商实际投递验收。收件内容保留在内存，报告仅保存是否通过；失败网关故意回显验证码时，断言应用响应和日志没有该值。
- Windows 中 `execFile` 启动 PowerShell，再由它启动后台 .NET 进程，后台进程可能继承输出管道，使启动器退出后 `close` 事件不结束。第 11 项改为 `spawn` 读取明确就绪消息，关闭捕获管道并释放引用；仍保留启动截止时间与 marker/PID 清理。
- 真实图形验证码使用服务生成的随机图片，读取隔离图片后填写；不设置固定正确答案，不直接写验证码缓存，不输出验证码文本。PTY 输入关闭回显，成功界面截图遮罩验证码。
- 拒绝场景必须断言目标错误，例如注册关闭 `D1034`、非法方案 `D1035`。仅断言非成功可能由重复手机号等更早错误误触发，不能证明目标边界。
- 可选密码注册同时检查持久化与真实密码登录。第 11 项通用属性复制遗漏密码，注册成功却保存了默认密码；只记录解密后与测试输入的布尔比较，绝不打印存储密文、明文或私钥。

### 2026-10-09：真实 LDAP 同步验收

- 第 12 项使用只绑定本机随机端口的临时 OpenLDAP 容器，真实执行绑定、搜索与目录密码登录；配置页、API、数据库映射分别断言。旧镜像仅用作短期隔离测试依赖，不作为生产部署建议。
- 目录组织同步先记录原机构主键，再重复同步，确认原机构存在且目录机构主键不变。只比较新增数量不足以发现“清空后重建”的破坏行为。
- 目录查询中途失败不能把部分结果当作完整快照；在写入前校验结果唯一性和租户，并在事务内替换账号映射。
- 凭据生成于测试进程内存，编辑截图遮罩密码，配置查询断言不回传密码，日志扫描仅输出布尔结果。容器清理前核验本项专用标签，再移除容器和它的匿名卷。

### 2026-10-09：令牌回跳与离开路由竞态

- 同一认证组件的 query 变化可能复用组件，不能只在 `onMounted` 消费候选令牌。第 13 项用不含敏感数据的入口序号区分导航，监听路由变化，并串行释放上一轮登录状态。连续旧登录链接应作为独立回归场景。
- 页面切换动画可能延后卸载。第 13 项契约验证，在返回登录页时仅依赖卸载或路由变化清理仍存在迟到响应被采用的窗口；使用 `onBeforeRouteLeave` 在导航确认前取消请求后通过。取消后的响应仍需校验会话代次及 `AbortSignal`。
- 旧回跳参数中的编码分隔符必须保留。反复调用安全路径校验不应把值内的 `%26`、`%23` 解码成查询或 hash 分隔符；同时仍拒绝外部路径、控制字符及递归认证地址。
- 认证页的 `toBeVisible` 不保证淡入动画已完成；`animations: disabled` 也曾截到半透明或空白。第 13 项改为等待 `document.getAnimations()` 中有限动画不再运行，再正常截图，实际查看确认稳定内容。忽略无限循环动画，避免等候永不结束。
