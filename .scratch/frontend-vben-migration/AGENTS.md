# 真实验收脚本约定

编写、修改、执行或排查本目录的 `run-*-baseline.mjs` 浏览器/集成验收脚本时，先读取并应用仓库根目录下的 `.agents/skills/real-browser-baseline/SKILL.md`。

每次执行结束，复核是否有可复用的新经验。已验证的经验同步更新该 Skill 的 `references/lessons.md`；未验证结论明确标记，不把单次运行结果固化成通用规则。无新经验时，在任务记录中注明已复核即可。

保留当前用户要求的桌面验收边界。Skill 不替代任务验收清单；契约、真实集成、视觉和清理分别记录。不要记录或提交测试凭据。
