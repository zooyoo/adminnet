## 实现

- 服务端发送限频、验证码失败次数限制、密码学随机数和登录原子消费，发送入口与直接自定义入口共享限制。默认有效期与发送间隔均为 60 秒；隔离测试缩短为 6 秒和 2 秒并实际等待过期。
- 自定义短信异常不回显网关正文、URL 或凭据；短信校验/发送、手机登录和注册禁用敏感请求监控。真实网关故意返回验证码，确认应用响应与 stdout/stderr 不包含该值。
- 手机登录允许隐藏租户选择时不提交租户，沿用账号所属租户；错误租户、停用账号、重复验证码均由真实 API 拒绝。
- 注册关联重新校验存在性及所属租户；匿名注册不读取匿名身份的管理范围。账号类型保护保留。
- 旧通用属性复制遗漏注册密码，导致指定密码被替换成默认密码。改为显式传递注册字段，SM2 传输密码解密后按现有算法存储；默认密码和自选密码均完成真实登录。
- 前端发送/提交期间锁定输入与重复操作，失败保留输入、恢复按钮；卸载和租户变化后忽略迟到结果及验证码响应。
- 隔离启动脚本仅允许本机 HTTP `/sms` 测试服务，并补齐公开默认 Logo；未读取运营商密钥或发送真实短信。
