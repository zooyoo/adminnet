# PDF 输出与打印服务

列表 PDF 与模板输出共用 pdfme 6.2.4。浏览器打印调用内嵌 PDF 的浏览器打印接口，取消系统打印对话框不算业务失败，也不显示物理打印成功。份数等设备参数由浏览器打印对话框选择。

## 客户端服务协议

这是 Admin.NET 的 HTTP 适配合同，不是 pdfme 官方服务。模板维护者配置受信任、已授权的绝对 HTTP/HTTPS 地址；执行时将生成的 PDF 发给该地址。PDF 包含预览数据或当前选择的数据，不附带登录令牌、Cookie 或 URL 凭据；禁止重定向。

- `POST`，请求体为 `application/pdf`。
- `X-Pdfme-Copies`：1 至 100 的整数。
- `X-Pdfme-Title`：URL 编码的任务标题，最多 200 字。
- 跨域服务需允许应用来源及上述请求头，并处理 CORS 预检。
- 响应须为 2xx、`application/json`，且 JSON 中 `accepted` 严格为 `true`。
- 超时为 30 秒；失败、拒绝或无有效回执不显示接收成功，不自动重试。
- 页面关闭或会话失效会取消未完成请求。已送达服务的任务不能通过取消 HTTP 撤销；请求失败后的重试可能重复送达，应先核对服务队列。

“已提交到打印服务”仅表示服务确认接收，不能证明纸张已打印。生产设备配置、队列认证和设备授权由部署方负责；本仓库验收只使用本机隔离接收服务，不操作真实打印机。

## 模板兼容

模板须为有效 pdfme JSON；不自动把其他引擎模板转换为示例。损坏模板禁止保存和执行，可经确认选择常用模板重建。常用模板包括 A4 文档、商品清单、100 × 80 mm 标签。中文字体为 Noto Serif CJK SC 2.003，保留历史键 `SourceHanSerifSC`；不是 SimSun。
