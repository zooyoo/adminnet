# 文件管理与预览迁移

日期：2026-10-09。对应提案 17、18，仅桌面验收。

## 功能对应

| 原功能 | 新实现 | 验证入口 |
| --- | --- | --- |
| `/platform/file`、`/system/file/index` | 保留数据库菜单和旧地址，使用 Vben 布局与 Antdv-Next 公共表格 | `run-file-browser-baseline.mjs` 的直达、刷新及查询 |
| 文件名称、日期及租户查询 | 名称筛选、单端或双端时间范围；超管可指定租户 | 真实列表与后端文件隔离测试 |
| 上传、类别及公开状态 | 复用 `/api/sysFile/uploadFile`，限制空文件、10 MB 和允许扩展名；服务端仍应用 Upload 配置 | 真实上传、非法输入、停机；浏览器取消及迟到响应契约 |
| 文件编辑 | 名称、类别、公开状态，以及现有实体的 `FileAlias`、`DataId`；只写元数据白名单 | SQLite 与真实 API 防篡改、浏览器编辑 |
| 下载 | 受认证 API 返回二进制，保留中文名称；错误复用统一请求拦截器 | 真实内容逐字节比对、中文下载名、单次鉴权提示契约 |
| 图片预览 | 使用认证请求取得 Blob，在统一弹窗展示；关闭及身份变化撤销对象地址 | 真实图片、Vitest 生命周期、浏览器对象地址释放 |
| DOCX、Excel、PDF | 延迟加载 `@vue-office/docx@1.6.3`、`@vue-office/excel@1.7.14`、`@vue-office/pdf@2.0.10`，传入认证获取的 ArrayBuffer | 本地生成的真实 DOCX、XLSX、PDF，经生产浏览器实际渲染 |
| 音视频 | 同一弹窗使用浏览器原生媒体引擎与控制条；不新增流媒体协议 | 本地生成 WAV 和 WebM，加载、播放、暂停与关闭 |
| 无法预览或损坏文件 | 不支持类型说明、渲染失败反馈、30 秒加载上限 | 本地 TXT、损坏 DOCX |
| 业务图片上传 | 通知编辑器复用公共上传适配层；头像明确公开；签名通过当前用户认证接口读取 | 个人中心真实头像和私有签名；相关个人资料契约 |

旧文件页面中的 `relationName`、`relationId`、`belongId` 没有对应的 `SysFile` 实体字段或生成 SDK 字段；只存在于未被该页面调用的 `RelationQueryInput`。本次保留实际持久化合同 `DataId`，不新增无后端语义的关联字段，也不将旧输入框当成已实现的关系管理。

## 权限与存储

- 查询、上传、下载、编辑、删除均要求已有 `sysFile:*` 权限。预览和 Base64 下载复用下载权限；批量上传和 Base64 上传复用上传权限，不能因缺少独立菜单按钮而默认放行。
- 公开文件保持原有共享读取语义。私有读取保留数据范围过滤，并额外限定当前租户；跨租户公开文件不因可读而允许修改或删除。
- 更新不能修改租户、创建者、后缀、物理路径、URL、大小或存储位置。文件名校验和上传大小校验先于写入及 MD5 去重。
- 去重限定身份、租户、公开状态、类别、业务数据、名称、后缀与目标路径。明确指定存储提供者时不复用其他提供者的记录；重复上传同一头像或签名不能删除刚复用的文件。
- 本地上传资源在 ImageSharp 和静态文件中间件之前检查公开状态；私有文件直链和图片转换地址拒绝访问。公开资源响应设置 `no-store`，公开转私有后新请求立即受保护。
- 当前真实验收使用本地存储、独立 SQLite 和临时运行目录。OSS、SSH 的已有提供者继续保留，本次不宣称验证外部云账户或远程存储。外部存储的私有桶策略及生产反向代理必须与应用权限一致；不能让代理直接公开私有上传目录而绕过应用检查。
- 历史记录中标记为私有、却曾依赖公开静态直链访问的资源，现在受私有策略约束。业务需要公开访问时应由有权用户明确设置公开；本次不批量修改历史数据的公开状态。

## 可重复验收

仓库根目录：

```powershell
$ErrorActionPreference = 'Stop'
node .scratch/frontend-vben-migration/run-file-contract-baseline.mjs
node .scratch/frontend-vben-migration/run-file-browser-baseline.mjs
```

前提：使用当前代码构建 `Web/dist`，并将 API 独立输出到系统 Temp 下的 `adminnet-vben-build-17`。真实脚本自行创建和校验隔离目录，启用 MD5 去重，使用 5016 端口；端口已占用时停止，不结束用户进程。

`file-fixtures.mjs` 在本地生成 PNG、DOCX、XLSX、PDF、WAV、WebM、TXT 和损坏文件，不获取远程测试资料。报告分别标记 `passed`、`cleanupPassed`，保留数据库和脱敏截图；完成后恢复角色授权及个人图片字段，核对文件记录和物理文件已清理，并停止 API、代理和浏览器。

具体最终报告位置、测试结果和视觉复核记录见 `.scratch/frontend-vben-migration/issues/17-file-management-images.md` 与 `18-office-media-preview.md`。
