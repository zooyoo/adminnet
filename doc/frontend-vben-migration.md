- 新应用目录：`Web/apps/web-antdv-next`；构建产物：`Web/dist`。
- 保留既有认证安全语义、租户数据隔离、菜单权限、业务 URL 和数据库数据。
- 分阶段验收，最终整体切换。不使用占位页、Mock 或旧应用 iframe 代替迁移。

## 接口约定

- 原认证和业务接口保留 `{ code, result, message, errors }`，成功码 `200`。
- 请求共享令牌与错误处理；生成 SDK 保留原始响应，业务适配层解包。
- 令牌续期继续使用 `Authorization`、`X-Authorization` 和响应头换发机制。
- 新增 Vben 菜单 DTO 与 `/api/sysMenu/vbenMenuTree`，保留原菜单接口。
- 新增 `/api/sysJob/previewCron`，使用后端现有 Cron 引擎计算后续 5 次运行时间。
- 列表分页使用 `{ page, pageSize, field, order }` 和 `{ items, total }`。
- 新前端使用独立缓存命名空间，首次切换重新登录，不迁移旧权限和令牌缓存。
