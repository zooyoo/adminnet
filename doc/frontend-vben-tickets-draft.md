# Vben 全量迁移任务拆分提案

日期：2026-10-08。

状态：等待用户确认粒度、依赖和测试边界；本文是拆分提案，不是已发布的任务集合。

来源：[Vben 迁移规格](E:/pri/Admin.NET/doc/frontend-vben-spec.md)及当前会话。规格中的“尚未配置 Issue tracker”是历史状态；本次已按正式配置采用本地 Markdown，不修改原规格。

## 拆分原则

- 保留全量迁移范围与已实现基线。已有 14 个系统模块主要补真实联调、遗漏行为和回归，不重新搭建工程或重复迁移页面。
- 每项交付一个能独立演示或验证的用户流程，包含必要的界面、现有或新增 API、数据行为和测试；不是先做全部后端、再做全部前端。
- 以下 48 项按一份新上下文可完成的范围划分。已有页面的联调任务可以覆盖相关模块；数据库、任务调度和代码生成按独立工作流进一步拆分。
- 每项只列直接阻塞它的任务；“无”表示能够在当前基线上开始，不表示外部测试服务已可用，也不表示能够跳过验收。
- 第 01 项建立可复用真实联调基线。只验证已有模块的任务依赖该基线；独立功能可先利用既有认证、SDK 和浏览器契约开始，不强制串成一条长链。
- 暂未识别出必须先执行的大范围前置重构。公共能力随第一个真实使用场景补齐，并保持现有调用兼容；不得引入与交付无关的重构任务。
- 保留已集成的 `Sundial.Dashboard` 前端；仅核验入口、鉴权及部署兼容，不替换其内部页面。

## 共同验收规则

这些规则在发布时会落实到各个独立任务的验收条件，不能只依赖阅读本提案。

1. 使用 Antdv-Next 实现 Admin.NET 自有业务 UI，包括表格；复用当前 Vben 工程和专用引擎，保持现有 API 与数据库兼容。
2. 主验收边界拟采用“生产构建浏览器 → 真实 API 或 SignalR → 隔离测试数据”，复用 Playwright 契约、Vitest 公开合同测试和后端临时 SQLite 测试补充错误与竞态场景。此边界尚待用户确认。
3. 新增或修改行为至少验证成功、输入校验、权限不足、服务失败和适用的租户隔离；只读检查、类型检查、相关测试与生产构建均应通过。
4. 契约通过、真实集成通过和视觉通过分别记录。第 46 项汇总已有证据并检查跨模块流程，不承担所有模块的首次真实联调。
5. 外部环境、账号或设备未就绪时，明确记录缺少的前提与待验收行为；不伪造已完成，也不以 Mock 结果关闭真实集成要求。准备期间不访问生产业务数据、不产生真实支付或真实消息。
6. 每项触及界面时核验桌面与手机布局、加载和错误状态；截图不能以浮层遮挡的瞬间画面代替稳定状态的检查。
7. 每项更新其负责的功能对应关系及证据，沿用当前已实现的真实行为；发现旧占位页时记录证据，不擅自扩展为新业务。
8. 既有生产白屏、权限清空及会话隔离回归持续保留。未再次复现的历史表单异步失败记为观察项，不宣称已修复。

## 编号提案

1. **真实账号登录与职位 CRUD 基线**

   - 阻塞于：无。
   - 交付：在隔离环境使用真实账号，从生产登录页进入职位列表，完成新增、修改和删除，再退出并重新登录。
   - 验收点：建立可重复的测试数据与启动方法；核验 SM2、验证码及二次验证、双令牌续期、失效提示；直达和刷新不白屏；数据库变化与界面结果一致，环境清理可验证。

2. **手机缓存页与全局浮层可操作性**

   - 阻塞于：无。
   - 交付：手机用户能够浏览缓存键、查看值、确认删除或清空，不被偏好设置按钮、通知和确认浮层阻挡。
   - 验收点：复现已记录的遮挡场景后修复；分组与真实键保持区分；有无通知、明暗主题和窄屏下操作可达；补浏览器回归和稳定状态截图，不改变缓存 API。

3. **在线用户、实时连接与强制下线**

   - 阻塞于：无。
   - 交付：登录创建真实 SignalR 会话，管理员可查看在线用户并强制下线；断网恢复、退出或换租户后连接跟随当前身份。
   - 验收点：核验 Hub 真实握手与令牌传递；重连采用当前令牌；多客户端下线对象正确；事件不重复注册，旧连接不能更新新会话。

4. **通知发布、收取与已读闭环**

   - 阻塞于：03。
   - 交付：管理员编辑并发布通知，目标用户收到真实消息，查看详情、标记已读后未读列表和数量一致。
   - 验收点：保留通知管理的现有操作与权限；覆盖离线后重新登录读取未读、重复事件处理及跨租户隔离；复用第 03 项会话连接，不另建通知连接生命周期。

5. **角色授权、菜单与旧地址真实验收**

   - 阻塞于：01。
   - 交付：管理员调整角色菜单和数据范围，目标用户重新访问后权限准确；旧菜单配置及业务地址继续可用。
   - 验收点：验证全选、半选、全部撤销及遗漏字段不改授权；服务端拒绝越权；保留目录、按钮、翻译、图标、隐藏、缓存、固定标签、外链和内嵌行为；加载失败不覆盖已有授权。

6. **用户、机构与职位关联真实验收**

   - 阻塞于：01。
   - 交付：维护人员在真实数据上管理组织结构、职位和账号，正确保存角色及附属机构，并执行复制、状态、密码重置和登录解锁。
   - 验收点：保留现有资料字段；机构父级不能形成环；角色可清空；跨租户选项不串用；失败保留草稿或服务端确认状态；沿用第 01 项职位回归。

7. **租户授权、隔离与身份切换真实验收**

   - 阻塞于：01。
   - 交付：维护租户隔离方式与授权，切换租户或进入租管端后获得正确身份和数据，失败时原会话仍可使用。
   - 验收点：覆盖授权同步、空授权、默认租户保护、字段隔离与库隔离；建库、删除、重置租管密码仅作用于隔离测试目标且需确认；迟到请求不能污染新身份。

8. **字典、参数与缓存一致性真实验收**

   - 阻塞于：01。
   - 交付：管理员修改字典、系统参数和租户参数后，业务页面按正确作用域读取新值，缓存刷新与管理操作不误删其他键。
   - 验收点：验证内置字典限制、枚举数值类型、排序样式及扩展字段；系统与租户参数不串用；特殊字符键读取和删除正确；旧会话返回值不重新填充新会话缓存。

9. **语言维护与翻译导入导出真实验收**

   - 阻塞于：01。
   - 交付：维护语言和翻译，下载模板、导入数据、处理部分失败工作簿，并导出选中数据；既有 AI 翻译入口能正确请求和反馈。
   - 验收点：检查真实文件内容、编码、文件名和持久化结果；二进制 JSON 错误与鉴权失效可识别；限制无权用户；AI 测试使用明确测试服务，不以成功 Mock 冒充真实结果。

10. **站点品牌、注册开关与注册方案真实验收**

    - 阻塞于：01。
    - 交付：租户管理员保存站点信息和 Logo、控制注册开关、维护注册方案；登录和注册入口体现当前租户配置。
    - 验收点：Logo 取消不泄漏到下一次保存；注册方案的机构、职位和角色随租户更新；加载失败禁止错误保存；开关与选项在刷新后仍正确。

11. **手机登录与注册端到端**

    - 阻塞于：10。
    - 交付：用户在配置允许的租户内获取短信验证码、手机登录或按注册方案创建账号，并进入相应权限的系统。
    - 验收点：复用第 10 项注册配置与测试方案；验证验证码错误、过期和重复发送限制；注册关闭及非法方案被拒绝；通过隔离短信测试服务验证完整流程，日志不保存验证码或密码。

12. **LDAP 配置、同步与登录**

    - 阻塞于：01。
    - 交付：管理员维护 LDAP 配置与原有同步操作，测试目录用户可按既有规则登录并获得正确组织和权限。
    - 验收点：使用隔离目录及测试账号；配置权限、连接失败、重复同步和用户映射正确；敏感凭据不泄漏；不改写既有认证协议。

13. **第三方令牌与既有登录入口兼容**

    - 阻塞于：01。
    - 交付：用户通过原系统已实现的第三方令牌入口建立完整会话，并保留与之关联的旧地址及回跳行为。
    - 验收点：有效、无效及过期令牌处理一致；成功后重新加载用户、菜单和权限；失败不留下半登录状态；核对原有扫码入口，未实现部分明确记录，不新造认证能力。

14. **锁屏、解锁与退出隔离**

    - 阻塞于：01。
    - 交付：用户锁屏后无法继续操作受保护内容，解锁恢复原工作上下文，退出则清除会话并回到登录入口。
    - 验收点：沿用原有解锁规则；错误输入可恢复；刷新、令牌失效和主动退出不绕过锁屏；旧请求与业务缓存不恢复已退出的状态。

15. **个人设置、偏好与水印**

    - 阻塞于：01。
    - 交付：用户维护已有个人资料和设置，主题、语言、标签页与水印根据真实配置展示并在重新进入后正确恢复。
    - 验收点：核对原有个人设置字段与保存规则；账号间偏好不泄漏敏感数据；头像沿用现有上传合同；手机端浮层不遮挡关键操作；不引入上游假账号数据。

16. **真实首页、工作台与日程**

    - 阻塞于：无。
    - 交付：用户使用原有已实现的首页组件、工作台配置和日程操作，并能访问关于页及明确的错误反馈页面。
    - 验收点：按原有首页组件逐项核对真实数据来源和交互；日程创建、编辑及现有提醒行为正确；移除上游假内容；未实现示例不扩展为新业务；配置恢复及手机布局正常。

17. **文件管理、上传下载与图片预览**

    - 阻塞于：无。
    - 交付：用户通过文件管理页上传、查询、预览图片、下载和删除文件，业务上传入口复用同一真实合同。
    - 验收点：权限、租户、大小类型限制和取消行为与旧系统一致；下载内容与文件名正确；二进制鉴权错误只提示一次；文件资源地址在生产模式下可用。

18. **Office 与媒体文件预览**

    - 阻塞于：17。
    - 交付：用户从第 17 项文件入口查看原有 Office、PDF 及媒体类型，使用现有专用引擎完成加载、切换与关闭。
    - 验收点：采用代表性真实文件；不支持类型与加载失败有明确反馈；切换文件时释放资源；受保护文件不能通过预览绕过权限；不下载远程资料替代缺失的业务测试文件。

19. **真实列表导出与打印**

    - 阻塞于：无。
    - 交付：用户在现有业务列表按筛选、选择及列设置导出数据或打印，输出符合当前列表的明确范围。
    - 约束：引入 pdfme（http://pdfme.com/docs/getting-started）来实现
    - 验收点：选择已有真实清单作为验收场景；明确当前页、选中项与全部结果的边界；核对列顺序、中文、文件内容和打印布局；复用现有公共表格输出，覆盖服务失败和权限不足。

20. **打印模板编辑、预览与执行**

    - 阻塞于：无。
    - 交付：用户维护打印模板、在pdfme设计器中编辑并保存，使用测试数据预览，再通过pdfme打印服务执行输出。
    - 约束：引入 pdfme（http://pdfme.com/docs/getting-started）来实现
    - 验收点：引入pdfme里一些常见的模版、打印参数等配置管理功能；真实模板保存后可重开；使用pdfme打印引擎；测试打印在授权设备或隔离服务执行，服务不可达时不能显示成功。

21. **任务定义与运行控制**

    - 阻塞于：无。
    - 交付：管理员查询、新建和修改原有任务定义，按权限运行、暂停、启动、取消或删除测试任务。
    - 验收点：保留已实现的任务类型、分组和参数；仅执行隔离测试任务；批量操作遵循原语义；页面状态与调度引擎一致；失败不造成假成功状态。

22. **触发器编辑与 Cron 运行预览**

    - 阻塞于：21。
    - 交付：管理员为第 21 项任务配置触发器，用可视化 Cron 编辑器查看后续 5 次运行时间并保存有效配置。
    - 验收点：新增预览端点复用现有 Furion 引擎和任务权限；明确表达式格式、起点、时区及边界错误；保留非 Cron 触发器配置；保存并运行后与预览规则一致；不引入旧 UI 依赖。

23. **运行记录、集群与保留调度看板**

    - 阻塞于：21。
    - 交付：管理员从任务查看真实执行记录和集群信息，并能继续访问原有独立调度看板。
    - 验收点：用第 21 项测试任务产生成功与失败记录；保留既有持久化等相关操作；`Sundial.Dashboard` 前端不替换，入口、鉴权及生产可用性与原行为兼容。

24. **数据库表与字段维护**

    - 验收点：操作目标清晰且危险操作确认；结构变更在隔离库中可反查；原有类型、主键、自增、默认值等配置不丢失；未授权用户不能操作；建立可复用连接与表选择交互。

    - 验收点：复用既有可视化引擎；关系与结构查询一致；空表、复杂关系和加载失败可处理；生产模式下画面非空且能够交互；不发明后端没有提供的关系。
