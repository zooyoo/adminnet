# 轻量国际化组合式函数

本目录为框架组件提供轻量国际化能力，具体接口以 [index.ts](index.ts) 为准，归属 `@vben-core/composables`。

应用业务文案由 `@vben/locales` 与 `apps/web-antdv-next/src/locales/` 管理。修改本目录时保持基础组件与应用语言资源的职责清晰，并核对已有调用方，不在这里引入业务页面或业务接口。

应用语言资源说明见[当前应用国际化](../../../../../apps/web-antdv-next/src/locales/README.md)，实现约束见[前端规则](../../../../../AGENTS.md)。
