本模块为仓库根级元数据集合，不承载业务实现：
- `README.md` 提供框架介绍、前后端入口（后端 `Admin.NET/Admin.NET.Web.Entry/`、前端 `Web/apps/web-antdv-next/`）、运行命令、依赖说明与内置功能索引。
- `AGENTS.md` 是全仓通用约定，覆盖项目结构、开发与验证流程、代码与提交规范、检索工具使用及协作文档维护边界。

- `.gitignore` 与 `.gitattributes` 控制版本库忽略策略与 Git 属性。
- `一键净化项目.bat` 是面向 Windows 的清理辅助脚本（编码非 UTF-8，由 Windows 批处理解析）。
这些文件共同构成仓库的对外说明与协作基线，实际代码逻辑位于 `Admin.NET/` 与 `Web/` 子树中。
